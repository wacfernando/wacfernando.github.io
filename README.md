# Adheesha Fernando | Portfolio

My personal portfolio website, showing my projects, research and experience as a data science undergraduate.

**Live site:** https://wacfernando.github.io

## What's on it

- Machine learning projects (restaurant pricing, student dropout prediction, property valuation)
- Research on urban accessibility and LLM prompting strategies
- Experience as an application support intern at Acumatica
- Skills, and ways to get in touch

## Built with

Plain HTML, CSS and JavaScript in a single `index.html` file, with canvas animations (an interactive dot network in the hero and a rippling dot grid in the background). Hosted for free on GitHub Pages.

## Run it locally

1. Download `index.html`
2. Open it in your browser, or run `python -m http.server 8000` in the same folder and go to `http://localhost:8000`
